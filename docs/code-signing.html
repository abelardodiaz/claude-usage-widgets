Code signing policy

Política de firma de código de los instaladores de Windows de claude-usage-widgets. English below.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.
Estado: solicitud en trámite. Hasta que se active, los instaladores se publican sin firma de Windows; las actualizaciones automáticas sí van firmadas con la llave propia del proyecto. La versión lite, que no tiene actualizaciones automáticas, hoy no lleva ninguna firma: solo su línea en SHA256SUMS.txt. Se firmará junto con los instaladores en cuanto la firma esté activa.

Qué se firma

  • Los instaladores de Windows de cada versión publicada en GitHub Releases: claude-usage-widgets_<versión>_x64-setup.exe y claude-usage-widgets_<versión>_x64_en-US.msi.
  • El ejecutable portable de la versión lite, publicado en el mismo release: claude-usage-widgets-lite_<versión>_x64.exe.
  • Solo se firman binarios construidos a partir del código de este repositorio. No se firma software de terceros.

Cómo se construyen

  • Cada versión sale de un tag vX.Y.Z sobre la rama main, que está protegida: nada entra sin pull request y sin los cinco controles del CI en verde.
  • El workflow .github/workflows/release.yml compila los instaladores en GitHub Actions, los firma y crea el release como borrador. Nadie compila en su equipo lo que se publica.
  • Cada firma requiere aprobación manual del responsable del proyecto, y el release solo se publica después de verificar los SHA-256 de SHA256SUMS.txt.

Las cuentas usan autenticación de dos factores en GitHub y en SignPath. Parte del código lo escriben sesiones de Claude Code que trabajan con la cuenta del responsable; todo cambio pasa por pull request, revisión y CI antes de entrar a main.

Privacidad

El programa no tiene telemetría ni servidores propios. Solo se conecta a otros sistemas para hacer lo que el usuario le pide al instalarlo y usarlo:

  • api.anthropic.com (Windows) o claude.ai (Android), para leer el uso del plan de Claude de la propia cuenta del usuario, con la credencial que ya tiene en su equipo. La credencial no sale del dispositivo hacia ningún otro sitio.
  • github.com, solo cuando el usuario pulsa Buscar actualizaciones.

Fuera de eso, este programa no transfiere información a otros sistemas de red, salvo que lo pida expresamente el usuario o quien lo instala u opera. El uso de esos servicios se rige por las políticas de privacidad de Anthropic y de GitHub.

English

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

  • What is signed: the Windows installers (-setup.exe and .msi) and the portable lite executable (claude-usage-widgets-lite_<version>_x64.exe) attached to each release on GitHub Releases. Only binaries built from this repository's source are signed.
  • How they are built: from a vX.Y.Z tag on the protected main branch, by the release workflow on GitHub Actions. Every signing request is manually approved, and releases are published as drafts first and checked against SHA256SUMS.txt.
  • Committers and reviewers: abelardodiaz. Approvers: abelardodiaz. Multi-factor authentication is enabled on GitHub and SignPath.
  • Privacy: no telemetry and no project servers. The program only contacts api.anthropic.com / claude.ai to read the user's own Claude plan usage, and github.com when the user clicks Check for updates. Otherwise, this program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.
